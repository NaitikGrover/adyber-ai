# 🧪 Ady Assistant - Simple Testing Checklist

Hold your hotkey (`Ctrl + Shift` or your configured key) and speak each question out loud to test Ady:

---

## 1. Local Apps Test (Known Apps)
- **Q1.** *"Open Discord"* (Should launch Discord desktop app)
- **Q2.** *"Open Google Chrome"* (Should launch Chrome browser)
- **Q3.** *"Open VS Code"* (Should launch Visual Studio Code)
- **Q4.** *"Open Notepad"* (Should launch Notepad)
- **Q5.** *"Open Calculator"* (Should launch Calculator)
- **Q6.** *"Open File Explorer"* (Should open Windows File Explorer)
- **Q7.** *"Open Terminal"* (Should launch Windows Terminal / PowerShell)
- **Q8.** *"Open MS Word"* (Should launch Microsoft Word)

---

## 2. Apps NOT on Computer (Autonomous Learning Test)
- **Q9.** *"Open Monkeytype"* (Should search web $\rightarrow$ open `https://monkeytype.com` $\rightarrow$ learn it)
- **Q10.** *"Open Linear"* (Should search web $\rightarrow$ open `https://linear.app` $\rightarrow$ learn it)
- **Q11.** *"Open Figma"* (Should search web $\rightarrow$ open `https://figma.com` $\rightarrow$ learn it)
- **Q12.** *"Open Claude"* (Should search web $\rightarrow$ open `https://claude.ai` $\rightarrow$ learn it)
- **Q13.** *"Open Anki"* (Should search web $\rightarrow$ open `https://apps.ankiweb.net` $\rightarrow$ learn it)

---

## 3. Chrome App / PWA Shortcuts Test
- **Q14.** *"Open YouTube Music"* (Should launch your installed `YouTube Music` Chrome App shortcut)

---

## 4. Websites Test (Known Websites)
- **Q15.** *"Open YouTube"* (Should open `https://www.youtube.com` in browser)
- **Q16.** *"Open Kick"* (Should open `https://kick.com` in browser)
- **Q17.** *"Open GitHub"* (Should open `https://github.com` in browser)
- **Q18.** *"Open Reddit"* (Should open `https://reddit.com` in browser)
- **Q19.** *"Open ChatGPT"* (Should open `https://chatgpt.com` in browser)
- **Q20.** *"Open Netflix"* (Should open `https://netflix.com` in browser)

---

## 5. Song & Music Playback Test
- **Q21.** *"Play God's Plan"* (Should open YouTube search for `God's Plan` with song ready at top)
- **Q22.** *"Play Starboy on YouTube Music"* (Should open YouTube Music search for `Starboy`)
- **Q23.** *"Play Jakhira on Spotify"* (Should open Spotify search for `Jakhira`)

---

## 6. Multi-Turn Follow-Up Test (Context Memory)
- **Q24.** 
  - **Step 1**: Say *"Open"*
  - **Ady asks**: *"What app or website would you like me to open?"*
  - **Step 2**: Say *"YouTube"* (Ady should understand and open YouTube)
- **Q25.**
  - **Step 1**: Say *"Who is Elon Musk?"*
  - **Step 2**: Say *"What is his net worth?"* (Ady should know "his" = Elon Musk)
- **Q26.**
  - **Step 1**: Say *"What is the weather in Tokyo?"*
  - **Step 2**: Say *"What about tomorrow?"* (Ady should check Tokyo's tomorrow forecast)

---

## 7. Live Web Search Test (with Sources)
- **Q27.** *"What is the latest tech news and AI updates today?"* (Should search live web and cite sources)
- **Q28.** *"What is the current stock price of Apple?"* (Should search live market price)
- **Q29.** *"Who won the cricket match yesterday?"* (Should search live match results)

---

## 8. Long-Term Memory Facts Test
- **Q30.** *"Remember that my favorite game is GTA 6"* (Should save fact to memory)
- **Q31.** *"What is my favorite game?"* (Should answer *"Your favorite game is GTA 6"*)
- **Q32.** *"What is my name?"* (Should answer with your name)
